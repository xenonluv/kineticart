# 4단계 서브에이전트 프롬프트 (haiku)

아래 `{IN}`·`{OUT}` 을 파트 경로로 바꿔 서브에이전트에 그대로 전달한다.
실행 규칙: 모델 haiku · 파트당 15건 · 동시 최대 3개 · 하나 끝나면 다음 하나 투입.
429/실패 파트는 비워 두고(대신 채우지 말 것) 한도 리셋 후 `prepare → split` 부터 재개.

---

키네틱 아트 데이터셋 작업이다. `{IN}` (JSON 배열) 의 항목마다:

1. `image` 경로를 Read 툴로 열어 **이미지를 직접 본다.** (이미지를 못 열면 그 항목은 결과에서 **빼라**. 원문을 베껴 채우지 마라.)
2. 판정 — 통과: 움직이는(또는 움직임을 표현한) 조각·설치·모빌, 바람/물/모터 구동물, 옵아트, 조에트로프·프락시노스코프 등 광학 장난감, 오토마타, 사운드 조각.
   거부: 건물 외관·전시장 전경·인물/작가 사진·도표·지도·포스터·책표지·일반 회화·풍경·정적 조각·공예품·작품이 안 보이는 사진.
   애매하면 통과 + `"uncertain": true`.
3. 통과 항목만 한글로 작성. `desc_src` 가 사실 근거다. 없는 사실은 쓰지 마라.
   `hint_artist` 는 대개 **사진가**, `hint_year` 는 **촬영일**이다 — 원문으로 확인 안 되면 `null`.

결과 배열을 `{OUT}` 에 UTF-8 JSON(한글 그대로)으로 저장한다.

거부: `{"local_id":"213","reject":true,"notes":"대통령 기념사진 — 작품 아님"}`
통과:
```json
{"local_id":"202","title_display":"한글 제목 (원어 제목)","artist":"한글 (원어) 또는 null",
 "created_year":1968,"materials_ko":"스테인리스 스틸, 모터",
 "description_ko":"1~2문장 요약 — 무엇이 어떻게 움직이는지.",
 "detail_text_ko":"3~5문장. 작가·배경·구동 원리·감상 포인트(근거 있는 범위).",
 "tags_ko":["키네틱아트","모빌","바람"],"uncertain":false,"notes":null}
```
규칙: 평서체(~이다). `tags_ko` 3~6개, 첫 태그 "키네틱아트". HTML 태그·영어 원문 복사 금지.
끝나면 "통과 N / 거부 M / 이미지 못 연 항목 K" 한 줄만 보고하라.
